# Tapering forms

## Construction guidance

Prefer gradual changes in cross-section over abrupt thick-to-thin transitions. Establish
the broad volume before narrowing the terminal region. Use several controlled shape
changes when a long form must taper.

## Evaluation signals

Check whether thickness decreases progressively, whether the silhouette remains legible
from multiple viewpoints, and whether the narrow region flows naturally from the primary
mass.

## Common failure modes

Abrupt pinching, repeated identical segments, a tip that appears attached instead of
continuous, and thickness changes that work from one view but fail from another.
