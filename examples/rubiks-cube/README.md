# Rubik's Cube

## Prompt

> Create a simple Rubik's Cube: a clean 3×3×3 grid of evenly spaced small cubes, with visible gaps between cubies and a recognizable cube silhouette.

## Status

This is a tested example that completed successfully with Aculptoi.

## Result

The observed run completed successfully in one construction iteration. Its dynamic
inspection atlas used 12 views and the final Critic score was 0.92. One remaining
low-severity issue was identified: the cubies were uniformly white rather than having
distinguishable Rubik's Cube face colors.

## What this example exercises

- Repeated geometry
- Regular spacing
- Multi-part construction
- Cube silhouette consistency
- Dynamic multi-view inspection
- Critic discovery and focused issue analysis

## Notes

Results may vary with the model, quantization, Blender version, and Aculptoi
configuration.
